# The-First-Step-to-Winning-Catan-Placement-Strategies
This repository holds the code and three example input files for the associated algorithm discussed in the paper of the same title.

When running the code, use a .txt file as a command line input to get the board into the algorithm.

It is important to format the .txt file correctly. See the .txt examples and use exactly the same format, just change the numbers and resource descriptions. See the file blank.pdf to see which hex is labeled A. The ports must be the same as seen in blank.pdf and hex A in your .txt file must be the same hex A in blank.pdf or the code will not work.
